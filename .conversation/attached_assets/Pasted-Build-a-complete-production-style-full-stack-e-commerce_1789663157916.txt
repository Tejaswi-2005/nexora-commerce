Build a complete, production-style, full-stack e-commerce web application called **NEXORA**.

This must NOT look like a generic AI-generated website or template. Design it as if an experienced product designer and full-stack developer built it manually.

The application should feel like a modern real-world e-commerce platform inspired by the usability and polish of leading shopping platforms, but DO NOT copy the branding, layout, assets, or design of any existing company.

The project must demonstrate:

* Frontend development
* Backend development
* Database design
* Authentication
* REST/API-style data operations
* Real-time database interactions
* Search and filtering
* Cart and checkout logic
* Order management
* Admin functionality
* Responsive UI/UX
* Animations and micro-interactions
* Security-conscious development

Use:

Frontend:

Users must NOT be able to modify:

Inventory

Another user's addresses
Admin data

Do not rely solely on hiding admin buttons in the frontend.
