## PRODUCT IMAGE REQUIREMENT

Every product must have a valid product image.

Do NOT reuse the same image repeatedly across different products.

Where suitable, provide **3–5 images for an individual product** so the Product Details gallery feels realistic.

For example:

Wireless Headphones

Image 1 → Front product view
Image 2 → Side view
Image 3 → Lifestyle/use image
Image 4 → Detail/close-up view

Store multiple product images using the existing:

product_images

database table.

Use:

product_id
image_url
alt_text
sort_order

The first image should be treated as the primary product image.

## IMAGE QUALITY

Images must:

* Match the actual product/category
* Be clear
* Have consistent visual quality
* Load correctly
* Have useful alt text
* Work on desktop and mobile
* Maintain proper aspect ratio
* Avoid stretching
* Avoid broken URLs

Do NOT display unrelated random images merely to increase image count.

Do NOT repeatedly use one placeholder image.

If reliable external images cannot be safely or consistently provided, create the correct image/storage structure and use appropriate development assets rather than inserting broken URLs.
